# Wellspace Project
### A simple habit-tracking app with a virtual room

Wellspace is a mobile app that helps users build better daily habits.  
The app shows a small virtual room where objects change based on the user’s real habits.  
For example: if you drink enough water, the plant grows. If you don’t walk enough, the dog becomes restless.  
This makes health easier to understand in a visual and relaxing way.

---

## Tech Stack
- **Flutter (Dart)** – Mobile frontend  
- **Node.js (Express.js)** – Backend server  
- **MySQL** – Database for user and habit data  
- **ngrok** – Secure tunnel for connecting the app to the backend during development  
- **Figma** – UI/UX design

---

## Simple Architecture
Flutter App ⇄ ngrok Tunnel ⇄ Node.js Backend ⇄ MySQL Database
